## 🚀 Current Projects

### 🔵 [Event Scout](https://github.com/aj-kivimaki/event-scout)

A system for finding and processing event information from the web.

It uses Python, FastAPI and n8n to collect event data, process and filter it, remove duplicates, and generate an email summary.

**Focus:**

* API development
* Data processing
* Web data collection
* Automation
* n8n workflows
* Docker

### 🟣 [RAG](https://github.com/aj-kivimaki/rag)

A local RAG system for working with documents and conversational context.

The project uses n8n, Ollama and local language models together with Python and PostgreSQL/pgvector to process documents, create embeddings, retrieve relevant information and provide context to an LLM.

**Focus:**

* RAG architecture
* Local LLMs
* Embeddings & vector search
* Document processing
* AI workflows
* n8n
* PostgreSQL / pgvector
* Docker
